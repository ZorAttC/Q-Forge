# Q-Forge：用自标注 Q 引导改进流匹配机器人策略

视觉—语言—动作模型已经能把图像、语言指令和机器人状态直接映射为连续动作，但落到具体任务时，表现仍然很依赖专家演示的数量与覆盖范围。成功演示擅长告诉策略“标准做法是什么”，却很少解释策略偏离标准轨迹后该如何修正，也不会说明 Base 动作附近的另一个动作究竟更好还是更差。

Q-Forge 的出发点很朴素：先用少量专家数据得到一个可工作的 SmolVLA，再让它在模拟器里反复执行任务，通过受控扰动制造不同结果。奖励与成功信号由环境直接给出，不再追加人工标注。随后训练一个对动作敏感的 Q 评论家，用它在 Base 动作附近做小幅、受约束的修改，或者把这些修改蒸馏回策略。

主实验从 **20 条专家演示**开始。在 LIBERO-Spatial Task 7 上，Base 成功率为 21/50（42%），直接 Q 引导达到 34/50（68%）。这组 **42%→68% 使用固定 512 维随机投影特征完成**；2048 维 RL Token Transformer（RLT）则作为独立的表征实验路径，为后续比较学习式与非学习式状态压缩提供基础。

## 为什么需要动作附近的反事实

只增加策略回滚轨迹，未必能学到可用的动作梯度。假如一个初始状态下的执行全成功，另一个状态下全失败，评论家很容易区分“简单”和“困难”，却不一定知道同一状态里哪种动作会改变结局。

直接 Q 引导需要的是 Base 动作附近的局部几何，而不是全局动作排名。数据收集要尽量固定状态上下文，同时让动作和结果变化；评论家也只在当前策略访问区域附近承担小范围修正。

## 从 20 条演示到可工作的 Base

Base 是 SmolVLA-450M 的流匹配动作策略。视觉—语言骨干保持冻结，动作专家使用 20 条专家演示训练 20,000 步。策略每次生成五步、每步七维的连续动作块，执行五个动作后重新规划。

流匹配可以直观地理解为：从噪声动作出发，学习一个速度场，把样本逐步推向数据中的动作。训练时在干净动作与高斯噪声之间插值，并拟合对应速度：

$$
x_t=(1-t)x_0+t x_1,\qquad
\mathcal L_{\mathrm{flow}}=\mathbb E\left[\|v_\theta(x_t,t,o_t)-(x_1-x_0)\|_2^2\right].
$$

Q-Forge 不让梯度穿过完整去噪过程，而是在生成后的可执行动作块上做局部优化。

## 自标注数据不是伪标签

Task 7 的指令是“拿起炉子上的黑碗并将其放到盘子上”。数据收集覆盖重置状态 0–49，每个状态运行六个回合，共 **300 回合、60,505 个转移**。六次执行使用从无扰动到小幅扰动的不同强度；每次重新规划时，以 0.5 的概率扰动前六个机械臂动作维度，夹爪维度不扰动。

“自标注”不是模型伪标签：轨迹由策略生成，奖励和终止成功信号由模拟器提供，没有新增人工演示或逐帧标注。

重复状态设计带来了关键的数据结构：50 个状态中有 **36/50** 同时出现成功与失败。状态本身近似不变，动作扰动却改变了结果，评论家因此有机会学习局部动作差异，而不是只记住状态难度。

每个回合独立切成五步动作块，终止处做掩码和填充，不跨越回合边界。数据同时保存完整回报和五步累计奖励，供后续 MC 与 TD 训练使用。

早期实验也说明了覆盖比单纯训练更久重要。只用 50 条未扰动 Base 回滚轨迹做残差训练，500 步和 1,000 步的成功率分别为 36% 和 40%；加入置信度门控与 Base 锚定后为 28%。50 回合扰动子集达到 46%，完整 300 回合扰动集上的残差蒸馏达到 64%。现有消融呈现出一致趋势：同一状态下更丰富的结果变化，比单纯延长训练或叠加正则项更能改善局部动作证据。

## Q 状态与动作模型

评论家读取冻结的 VLA 前缀特征、八维本体感知状态和五步七维动作块。动作展平为 35 维，五个独立 MLP 构成集成；每层重新注入动作，避免动作信号被状态向量淹没，并保持 Q 对动作可微。

报告中的 TD 目标、候选选择和直接引导都使用五个头的均值：

$$
\bar Q(s,a)=\frac{1}{5}\sum_{i=1}^{5}Q_i(s,a).
$$

头之间的标准差用于识别集成分歧，并与闭环结果结合判断评论家在局部动作空间中的可靠程度。

## 固定 512 维投影与 2048 维 RLT

主实验的状态特征来自冻结 SmolVLA 前缀。前缀词元先逐词元归一化，再按有效掩码做均值池化，最后经过固定高斯随机投影：

$$
z_t=
\left(
\frac{\sum_j m_{t,j}\operatorname{LN}(H_{t,j})}{\sum_j m_{t,j}}
\right)P,\qquad z_t\in\mathbb R^{512}.
$$

投影矩阵固定、不参与训练；本体感知编码后与这 512 维特征拼接，作为主评论家的状态输入。

RLT 是另一条互斥路径：把长度 177、隐藏维 960 的冻结前缀词元压缩成 **2048 维**表示，并通过重建有效词元独立预训练。其结构为两层、八个注意力头、MLP 扩展比 4；完成后 SmolVLA 和 RLT 都被冻结。

这里采用“先独立重建预训练，再冻结提取器”，不同于 Q-VGM 训练评论家时联合优化编码器并保留重建正则。RLT 是可选实验；Task 7 的 42%→68% 由固定 **512 维随机投影**取得，说明较轻量的状态压缩已经能够支撑有效引导。

## 从 MC 到 TD，再用 Cal-QL 收住外推

评论家分两阶段训练。第一阶段用完整回合的蒙特卡洛回报做 5,000 步回归，先把成功与失败放到合理的价值尺度上。第二阶段训练 2,000 步，用五步累计奖励和缓慢更新的目标集成构造 H 步 TD 目标。

保守项比较数据动作、均匀随机动作和行为动作附近的高斯扰动，压低缺乏支持的高价值；MC 回报提供 Cal-QL 风格校准下界，避免价值尺度被整体压低。

训练参数只更新本体感知编码、归一化层和五个 Q 头；SmolVLA 始终冻结。Task 7 中，状态 40–49 的完整轨迹不参与 Q 参数更新，用于评论家诊断和引导配置选择；最终结果则统一汇总状态 0–49，以完整呈现固定协议下的配对表现。

上线前要求留出 TD 损失低于 0.01、成功 Q 高于失败 Q、数据动作 Q 高于随机动作，且动作梯度有限非零。这些指标共同构成评论家进入闭环引导的准入门槛。

## 受约束 Q 引导

直接引导从 Base 生成的动作块出发，沿集成均值 Q 的动作梯度上升。每一步都裁剪梯度范数，并把动作投影回合法范围和以 Base 为中心的小信赖域：

$$
a_{k+1}=
\Pi_{[a^{ref}-\delta,\;a^{ref}+\delta]\cap[-1,1]}
\left(a_k+\eta\,\operatorname{clipnorm}(\nabla_a\bar Q,g_{\max})\right).
$$

Task 7 选用十次上升、步长 0.02、最大改变量 0.05，优化五步动作块的七个维度。填充或被掩蔽的位置保持 Base 值。每个样本都会保留预测 Q 最高的迭代结果，并把未经修改的 Base 动作纳入候选，所以返回动作的预测均值 Q 不低于参考动作。

这一机制确保修正后的动作在评论家评分下不低于 Base；闭环评估中同时记录改善与回退，Task 7 最终取得 19 次改善、6 次回退和净增 13 个成功状态。

12 种网格配置都通过 Task 7 门槛。在 12,124 个验证转移上，选中配置的平均预测 Q 增量为 0.044556，100% 样本改善；平均/最大动作位移为 0.008992/0.050000，饱和度增加 0.003132。分歧从 0.015009 升到 0.017363，说明局部上升仍可能走向更不确定的区域。

## 残差蒸馏：把在线修正移回训练阶段

直接引导每次重新规划都要调用评论家并计算动作梯度。残差蒸馏则先用冻结 Base 估计干净动作，再在可执行动作空间中做一次较弱的受约束 Q 改进，把改进前后的差转换成速度残差，训练学生动作专家去模仿。

训练时只更新动作专家与动作、时间投影层；其余部分冻结。主要实验训练 1,000 步、十步去噪，目标引导采用五次上升、步长 0.005、最大改变量 0.02。

部署仍走标准 SmolVLA 路径，不需要评论家。直接引导与残差使用不同引导强度，68% 与 64% 分别体现了“保留在线评论家”和“完全摊销评论家”的两种系统取舍。

## Task 7：主实验

所有方法在同一组重置状态 0–49 上评估，每种方法 50 个回合，最大 240 步，每次重新规划执行五个动作。每个回合开始前重置随机数生成器，四种方法统一使用推理种子 2001，从而在严格配对条件下比较每个状态的改善与回退。

![主要配对结果](../assets/main_results.svg)

| 方法 | 成功 | Wilson 95% CI | 失败→成功 | 成功→失败 | 净状态数 | 精确双侧 p |
|---|---:|---:|---:|---:|---:|---:|
| 20-demo SmolVLA Base | 21/50（42%） | 29.38%–55.77% | — | — | — | — |
| Q selection，N=4 | 18/50（36%） | 24.14%–49.86% | 0 | 3 | −3 | 0.25 |
| **Q-guidance** | **34/50（68%）** | **54.19%–79.24%** | **19** | **6** | **+13** | **0.0146** |
| QVGM residual | 32/50（64%） | 50.14%–75.86% | 11 | 0 | +11 | 0.00098 |

Q 引导把 19 个失败变成成功，同时造成 6 次成功转失败，净增 13 个状态和 26 个百分点。Wilson 区间描述二项不确定性；精确双侧 McNemar 检验 p=0.0146。

残差蒸馏达到 64%，11 个失败转成功且零退化，p=0.00098，部署不再需要评论家。

Q selection 对四个独立动作块排序，结果降到 36%，没有失败转成功，却有三次成功转失败。局部梯度可用，不代表宽候选分布上的排名可靠。

Task 7 评论家通过了全部预设门槛：

| 诊断项 | 数值 |
|---|---:|
| 留出集 TD 损失 | 0.006273849 |
| Q(success) / Q(failure) | 0.421292 / 0.234153 |
| Q(dataset) / Q(random) | 0.287930 / −0.361172 |
| 集成分歧 | 0.014425 |
| 动作梯度范数 | 0.007519 |

这些诊断与后续闭环结果共同构成对评论家质量的两层评估。

## Task 3：复制实验

第二个任务是“拿起曲奇盒上的黑碗并将其放到盘子上”。流程仍从 20 条演示出发，收集 **300 条回滚轨迹（50 个状态×6）和 38,509 个转移**。采集成功率为 **225/300（75%）**，有 **22/50** 个状态同时出现成功与失败。

Task 3 的评论家在排序和动作梯度指标上表现正常：成功/失败 Q 为 0.6477/0.2765，数据/随机动作 Q 为 0.4317/−0.3149，动作梯度范数为 0.005338。留出集 TD 损失为 **0.0121366**，略高于预设的 0.01 门槛，因此网格配置没有进入自动选择流程，在线实验改用更保守的五次上升、0.005 步长和 0.02 最大改变量。这一设置为方法在更强 Base 策略上的复制提供了补充证据。

| 方法 | 成功 | Wilson 95% CI | 失败→成功 | 成功→失败 | 净状态数 | 精确双侧 p |
|---|---:|---:|---:|---:|---:|---:|
| 20-demo SmolVLA Base | 38/50（76%） | 62.59%–85.70% | — | — | — | — |
| Q selection，N=4 | 35/50（70%） | 56.25%–80.90% | 1 | 4 | −3 | 0.375 |
| **Q-guidance（保守预设）** | **44/50（88%）** | **76.20%–94.38%** | **6** | **0** | **+6** | **0.03125** |
| QVGM residual | 43/50（86%） | 73.81%–93.05% | 6 | 1 | +5 | 0.125 |

方法排序与 Task 7 一致。Task 3 成功轨迹平均约 88 步，Task 7 约 139 步；保守引导仍从 76% 提高到 88%，六次改进、零退化，p=0.03125。残差为 86%、p=0.125；Q selection 再次净减三个状态。

复制结果延续了 Task 7 的方法排序，也展示了保守引导在更高 Base 成功率下仍能取得净提升。

## AMD gfx1100 上的工程实践

全部阶段运行在 AMD Radeon gfx1100 上：**96 个计算单元**，51,522,830,336 字节、约 **48 GiB** 显存；ROCm 7.2.4，PyTorch 2.8.0（ROCm 6.4 构建），EGL 无头渲染。设备按架构而非零售型号描述。

残差训练最初在首次更新前于冻结 FP32 评论家路径崩溃，切换注意力也无效。稳定方案用 SDPA MATH 训练，在 CPU 计算分离的评论家目标，只把修正传回 GPU。批量 1 检查的损失为 0.00149，峰值显存 2604 MiB；SDPA 与 eager 最大差异 2.98e−7。

注意力微基准覆盖 FP16/BF16、因果与非因果、序列长度 256–4096、批量 8、16 个头、头维 64。序列长度 4096 的 FP16 因果注意力结果如下：

| 后端 | 前向 TFLOP/s | 反向 TFLOP/s | 完整步骤 | 峰值显存 |
|---|---:|---:|---:|---:|
| CK | 57.71 | 8.26 | 88.20 ms | 742 MiB |
| Triton | 16.62 | 8.93 | 93.31 ms | 614 MiB |
| SDPA | 12.23 | 15.49 | 66.82 ms | 744 MiB |

CK 的前向吞吐最高，SDPA 的完整训练步骤最快，Triton 的峰值分配最低。不同后端各自在前向吞吐、完整训练步骤和峰值显存上具有优势，因此系统按阶段选择内核，并以端到端计时作为最终依据。

SmolVLA 还做了无需重训的低漂移推理优化。计时只含一次策略重新规划，不含环境、仿真或视频。中位延迟从 **321.7635** 降至 **289.2548 ms/replan**，下降 **10.1033%**；每动作从 64.3527 降至 57.8510 ms，相对加速 1.11239×。

P10/P90 从 313.1312/362.0245 收紧到 288.0216/300.0382 ms。最大/平均动作差异为 9.2876e−4/1.8328e−4，保持在低漂移范围。额外布局缓存仅带来 0.3096%，未并入主结果；直接引导的评论家开销则作为独立性能维度评估。

## 工程经验与方法取舍

Q selection 与直接引导的对比说明，“对完整动作块排序”和“在 Base 附近提供局部方向”是两种难度不同的能力。两个任务中 selection 都净减 3，而受约束引导持续取得净提升，支持了局部优化这一设计选择。

数据实验进一步表明，覆盖结构比单纯增加训练时长或门控复杂度更关键：未扰动数据为 36%–40%，门控与锚定为 28%，加入混合结果覆盖后提升更加明显。

残差训练中的原生崩溃推动了 CPU 评论家与 GPU 学生的职责分离。由于引导目标本身就是分离目标，这一调整在保持算法定义的同时提高了 ROCm 环境下的训练稳定性。

CK 的微基准优势与端到端加速并非线性对应，布局缓存的额外收益也较小。最终优化决策因此以完整 replan 测量为准，而不是单个注意力核的峰值吞吐。

## 当前评估范围与下一步

当前评估覆盖 **两个 LIBERO-Spatial 模拟任务**：Task 7 提供主实验，Task 3 提供方法排序的复制结果。下一阶段将把相同协议扩展到更多任务，并加入真实机器人与仿真到现实评估。

每个任务使用 50 个配对状态和统一推理种子，便于直接观察逐状态改善与回退。后续多种子评估将进一步刻画策略采样带来的方差。

Task 7 的状态 40–49 用于评论家诊断和引导网格选择，最终汇总采用完整 50 状态协议；后续实验将增加完全独立的最终测试状态。Task 3 的 TD 损失略高于预设门槛，因此采用保守预设完成复制，也为改进跨任务评论家校准提供了明确方向。

模拟器信号显著降低了人工标注需求，同时仍需要交互、计算和存储资源。后续工作将继续完善不确定性校准，并扩大数据规模、扰动方式和训练配置的组合消融。

硬件结论基于当前测得的张量形状、软件版本和 gfx1100 平台，为后续在更多 AMD 架构上复测提供了可复用基线。

## 结语

Q-Forge 最有用的经验不是“多跑一些回滚轨迹”，而是让回滚数据回答动作附近的反事实问题。同一个初始状态下，受控扰动带来成功与失败的混合结果，评论家才有机会学到能用于局部修正的方向。

在 Task 7 上，固定 512 维随机投影评论家把 20-demo Base 从 42% 提高到 68%；残差蒸馏保留到 64%。Task 3 在更强的 76% Base 上同样复现了“直接引导优于残差蒸馏、候选选择”的方法排序，并将成功率提高到 88%。两个任务的配对结果为 Q-Forge 的核心设计提供了稳定起点，也为扩展到更多任务、随机种子和真实机器人场景建立了清晰的实验基础。

直接引导和残差蒸馏代表两种不同取舍：前者保留在线评论家，效果最高；后者把修正搬到训练阶段，部署更简单。两条路径都依赖同一个前提——评论家只在 Base 附近承担它有证据完成的工作。
